# Deployment Guide

This guide explains how to deploy your TanStack Start application to various hosting platforms.

## Vercel Deployment 🚀

This application is configured for seamless deployment to Vercel using the Nitro build system.

### Prerequisites

1. Install the Vercel CLI:
   ```bash
   npm i -g vercel
   ```

2. Login to your Vercel account:
   ```bash
   vercel login
   ```

### Deployment Steps

1. **Build the application:**
   ```bash
   bun run build
   ```

2. **Deploy to preview:**
   ```bash
   bun run deploy
   ```

3. **Deploy to production:**
   ```bash
   bun run deploy:prod
   ```

### Alternative: GitHub Integration

You can also deploy by connecting your repository to Vercel:

1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Import your GitHub repository
4. Vercel will automatically detect the configuration and deploy

### Build Configuration

The application uses:
- **Build Command:** `cd ../.. && bun run build --filter=web`
- **Install Command:** `cd ../.. && bun install`
- **Output Directory:** `.vercel/output/static` (automatically generated by Nitro)

### Environment Variables

If your application uses environment variables, make sure to set them in your Vercel dashboard:

1. Go to your project settings in Vercel
2. Navigate to "Environment Variables"
3. Add your variables for Production, Preview, and Development as needed

### Troubleshooting

**Build fails with nitro errors:**
- Make sure all dependencies are installed: `bun install`
- Try clearing the build cache: `rm -rf .vercel .output dist`
- Rebuild: `bun run build`

**404 errors after deployment:**
- Check that the Nitro build completed successfully
- Verify the `.vercel/output` directory was created during build

**Monorepo deployment issues:**
- Ensure the build command includes the monorepo context: `cd ../.. && bun run build --filter=web`
- The install command should also run from the monorepo root

## Development Preview

To test the production build locally:

```bash
# Build the application
bun run build

# Start the server
bun run start
```

The server will be available at `http://localhost:3000`.
